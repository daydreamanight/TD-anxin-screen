# 安芯讯屏 用户说明书

安芯讯屏用于教学楼、实验楼、图书馆等校园公共空间，在没有网络的情况下显示通知、提示和活动路线，并可由管理员人工发布应急演练提示。显示内容保存在 TF 卡中，开机后自动轮播，不需要连接电脑。

> **注意：** 本产品没有火情探测和自动报警功能。应急提示由管理员人工发布，页面上的路线是预设演练路线。发生实际险情时，请以现场工作人员和广播指引为准。

## 1. 硬件连接

| 连接 | 说明 |
|---|---|
| HDMI 线 | 开发板 HDMI A 口接显示器，声音也经 HDMI 输出 |
| USB 线 | 开发板供电 |
| USB 串口线（可选） | 接电脑，用于串口工具；不接也能正常运行 |
| TF 卡 | 关机后插入，FAT32 格式 |

## 2. 开机与关机

1. 连接显示器，并打开显示器和音量。
2. 确认 TF 卡已插好，打开电源开关。
3. 等待几秒，屏幕自动显示第一页并开始轮播，顶部显示 `AUTO`。

使用完毕直接关闭电源开关。**插拔 TF 卡前请先关机。**

## 3. TF 卡准备

把下列文件放在 TF 卡**根目录**，文件名不能改，不要放进子文件夹。本代码包的 `sd_card/` 目录提供了示例内容。

| 文件 | 用途 |
|---|---|
| `PIC1.BMP` | 今日通知 |
| `PIC2.BMP` | 应急页，只在发布应急时显示 |
| `PIC3.BMP` | 天气与停电提示，切换到此页时响提示音 |
| `PIC4.BMP` | 活动日引导，可显示路线 |
| `PIC5.BMP` | 设备与操作说明 |
| `SCREEN.CFG` | 播放设置 |

图片要求：24 位未压缩 BMP，宽不超过 1024、高不超过 768，会自动缩放到全屏。

## 4. 按键

| 操作 | 功能 |
|---|---|
| 按 KEY2 | 下一页，同时转为手动（顶部显示 `MAN`） |
| 按 KEY4 | 上一页，同时转为手动 |
| 按 KEY3 | 在自动轮播和手动之间切换 |
| 在活动日引导页长按 KEY2 约 1 秒 | 切换路线 R1、R2、R3；R0 表示不显示路线。路线在关机或复位前一直保持 |
| 同时短按 KEY2 和 KEY3 | 发布应急提示 |
| 同时按住 KEY2 和 KEY3 约 1 秒 | 进入或退出维护 |
| 按 KEY1 | 复位，重新读取 TF 卡 |

## 5. 屏幕顶部状态

| 显示 | 含义 |
|---|---|
| `PAGE n` | 当前页码 |
| `AUTO` / `MAN` | 自动轮播 / 手动停留 |
| `WAIT` / `LOCK` | 正在切换到应急页 / 应急提示已锁定 |
| `FAIL` | 读图或应急失败 |
| `INFO` / `WARN` / `ALERT` | 通知 / 警示 / 应急页面 |
| `R0`～`R3` | 活动日引导页当前路线 |

屏幕底部是滚动字幕。没有图可显示时，屏幕中央显示 `LOADING` 或 `NO IMAGE`。

## 6. 应急操作规程

1. **发布：** 同时短按 KEY2 和 KEY3。屏幕显示 `WAIT`。
2. **确认：** 切换到应急页后显示 `LOCK`，并响一次提示音。此时屏幕采用默认亮度和对比度。
3. **保持：** 锁定期间页面不会被翻走，普通按键不起作用，轮播停止，串口切换也会被拒绝。
4. **解除：** 只按住 KEY3 约 2 秒。屏幕仍停在应急页，亮度和对比度恢复原设置；如果之前是自动轮播，稍后继续轮播。

> **如果屏幕显示 `FAIL`，说明应急页没有显示出来，请立即改用广播或现场通知。** 处理后检查 TF 卡，再按 KEY1 复位。

设备处于维护状态时不能发布应急，请先同时按住 KEY2 和 KEY3 约 1 秒退出维护。

## 7. 设备维护（管理员）

1. 同时按住 KEY2 和 KEY3 约 1 秒进入维护，轮播暂停，顶部显示参数和运行状态。
2. 同时短按 KEY2 和 KEY3，依次选择 B、C、W、S，当前项显示为青色。
3. 按 KEY2 增加或开启，按 KEY3 减少或关闭。
4. 再次同时按住约 1 秒退出，设备保持手动，按 KEY3 恢复自动轮播。

| 项目 | 说明 | 默认 |
|---|---|---|
| B 亮度 | 0～8 | 4 |
| C 对比度 | 0～4。0 档文字可能不清晰，一般不使用 | 2 |
| W 波形 | 1 在维护界面显示音频波形，0 关闭 | 1 |
| S 声音 | 1 页面提示音，0 连续测试音（用于检查声音） | 按配置文件 |

维护界面还显示 `UP`（开机后运行秒数，不是当前时间）、`ERR`（错误码）和 `STATE`（状态码）。

**建议：** 维护结束后把亮度和对比度调回默认，或按 KEY1 复位。复位和关机后，参数都恢复默认。

## 8. 播放设置 SCREEN.CFG

文本文件，不超过 512 字节，例如：

```text
VERSION=1
ORDER=1,3,4,5,2
ENABLED=10111
HOLD=8,9,9,9,9
MODE=SCENE
```

| 字段 | 说明 |
|---|---|
| `VERSION` | 固定为 1 |
| `ORDER` | 播放顺序，1～5 各出现一次 |
| `ENABLED` | 依次对应 PIC1～5，1 参与轮播，0 不参与，不能全为 0。PIC2 关闭后仍可发布应急 |
| `HOLD` | 依次对应 PIC1～5 的停留秒数，每项 1～9 |
| `MODE` | `SCENE` 页面提示音，`TEST` 连续测试音 |

五个字段都必须有，且每个只写一次。`#` 后面是注释；空格会被忽略。

**默认行为：** 文件缺失或任何一项写错，都整份回到默认：PIC1～5 全部轮播，每页 5 秒，连续测试音。

## 9. 串口工具（可选）

串口工具在 `pc_tool/` 目录，只在本机运行，不联网。

1. 安装 Python 3 和 pyserial：`pip install pyserial`。
2. 双击 `pc_tool\tools\serial_control\start.cmd`，浏览器打开控制台。黑色窗口要保持开着。
3. 选择串口，点“连接”。参数固定为 115200、8N1。
4. 可以翻页、指定页面、切换手动和自动、查询状态。

通信记录里每条命令有两次回执：“已接受”表示设备收到命令，“已呈现”表示新画面已经显示。

串口是有线辅助控制，不能发布应急。锁定或维护期间切换命令显示“已锁定，拒绝”；未启用的页面显示“页面不可用”。同一个串口同时只能被一个程序使用。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 屏幕无画面 | 检查电源和 HDMI 线；开机后画面需要等待几秒 |
| 显示 `NO IMAGE` | TF 卡未插好或图片不可用，关机检查后重新开机 |
| 应急页进入轮播且一直响 | `SCREEN.CFG` 缺失或写错，按第 8 节改正后重新开机 |
| 按键翻不了页 | 设备处于 `LOCK` 或维护状态，先解除或退出 |
| 进入维护后看不到参数 | 顶部显示 `FAIL` 时不显示参数，按 KEY1 复位后再进入 |
| 没有声音 | 检查显示器音量。今日通知和设备说明页本来没有提示音 |
| 采集卡没有画面 | 部分采集卡不能接收本设备的信号，请直接连接显示器 |
